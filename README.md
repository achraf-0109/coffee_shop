# ☕ Brew Haven — Coffee Shop Website

A single-page website for a fictional coffee shop, built with **HTML, CSS, and JavaScript**. This project was created for learning purposes to practice front-end web development fundamentals.

## 📖 About

Brew Haven is a one-page (single-page) static website showcasing a coffee shop's brand, story, and offerings. All sections live on one scrollable page with smooth navigation between them — a great way to practice semantic HTML, responsive CSS, and interactive JavaScript without relying on any frameworks or libraries.

## 🗂️ Sections

| Section | Description |
|---------|-------------|
| Home | Hero section with intro and call-to-action |
| About | The coffee shop's story and mission |
| Menu | List of drinks, food items, and prices |
| Gallery | Photo gallery of the shop, drinks, and ambiance |
| Testimonials | Customer reviews and feedback |
| Contact | Contact form, location, and opening hours |

## 🛠️ Built With

- **HTML5** – semantic page structure and content
- **CSS3** – styling, layout (Flexbox/Grid), and responsiveness
- **JavaScript (Vanilla)** – interactivity (e.g. smooth scroll navigation, mobile menu toggle, gallery lightbox, form validation)

## ✨ Features

- Responsive design that adapts to desktop, tablet, and mobile screens
- Sticky/fixed navigation bar with smooth scrolling to each section
- Mobile-friendly hamburger menu
- Interactive gallery and testimonials
- Contact form with basic client-side validation
- Clean, semantic HTML for accessibility and SEO best practices

## 🚀 Getting Started

No build tools or installations required — this is a static site.

1. Clone or download this repository
2. Open `index.html` in your browser, **or**
3. Use a live server (e.g. the VS Code "Live Server" extension) for auto-reloading during development

```bash
git clone <your-repo-url>
cd coffee-shop-website
```

Then simply open `index.html` in your browser.
